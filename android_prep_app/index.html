Compose Stability & Skipping Rules

  • List<T> is UNSTABLE: Standard interfaces cannot guarantee immutability. Use ImmutableList<T> or annotate data classes with @Immutable.
  • Unstable Lambdas: Inline lambdas recreate instances on every recomposition. Use remember(key) { { action() } } or method references.
  • derivedStateOf: Use when an input state updates frequently (e.g., scroll pixels) but the UI only cares about a threshold (e.g., offset > 50).
  • Phase Skipping: Defer state reads to Layout or Draw phase (using Modifier.offset { ... }) to bypass composition phase entirely.
🧵

Coroutines & Structured Concurrency

  • Job vs SupervisorJob: In standard Job, any child failure cancels the parent and siblings. SupervisorJob isolates failures to the failing child only.
  • CoroutineExceptionHandler: Only works on top-level root coroutines launched with launch; ignored if passed to child coroutines.
  • StateFlow vs SharedFlow: StateFlow always has an initial value, replays 1, and filters duplicates (distinctUntilChanged). SharedFlow is for one-time events without replay.
  • Mutex vs Synchronized: Always use Mutex.withLock in coroutines to suspend rather than block OS threads.
📱

Android 14 & 15 Platform Changes

  • Strict FGS Types: Foreground Services MUST declare explicit foregroundServiceType in both AndroidManifest and in startForeground().
  • 16 KB Page Size: Android 15 introduces 16 KB memory page size support. Native C++/JNI libraries must be recompiled with 16KB alignment.
  • Predictive Back Animation: Requires android:enableOnBackInvokedCallback="true" and migrating to BackHandler in Compose.
  • Doze & App Standby: Network requests during Doze require high-priority FCM messages or expedited WorkManager jobs.
🛡️

OWASP Mobile Top 10 Security Checklist

  • Android Keystore: Generate cryptographic AES-GCM keys inside hardware-backed TEE / StrongBox; never hardcode salt or keys in source code.
  • Certificate Pinning: Configure pin sets in res/xml/network_security_config.xml with backup pins to avoid app breakage on cert expiry.
  • Database Encryption: Use SQLCipher with Room DB, deriving the database encryption passphrase dynamically using Keystore.
  • Root & Anti-Tamper: Check for test-keys build tags, su binaries, and implement Play Integrity API for server-side attestation.
