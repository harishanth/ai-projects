# Android Lead & Staff Interview Prep Studio

An interactive preparation studio tailored for Senior, Lead, and Staff Android Engineer interviews.

## Features

- **System Design & Architecture**: Clean architecture, modularization patterns, offline-first architectures, state management.
- **Modern Android Stack**: Jetpack Compose, Kotlin Coroutines & Flow, Dependency Injection, Room, WorkManager.
- **Deep Internals**: Concurrency, memory profiling, ART runtime, Binder IPC, render pipeline optimization.
- **Interactive Flashcards & Quiz Modes**: Self-assessment and targeted interview review.

## Getting Started

### Option 1: Run with Local Python Server (Recommended)
```bash
./run.sh --server
```
Or:
```bash
python3 server.py
```
Open [http://localhost:8090](http://localhost:8090) in your browser.

### Option 2: Direct Browser View
```bash
./run.sh
```
Or open `index.html` directly in your browser.
